# Volnami C7 — исходники v646

Ветка `source-v646` содержит актуальный Next.js-проект и авторскую Three.js-сцену. Ветка `main` в этом репозитории хранит прежнюю статическую публикацию v615; её содержимое этим push не заменяется.

## Запуск

Проверено на Node.js 24.1.0. Версии зафиксированы в package-lock.json: Next.js 15.5.29, React 19.1.1, Three.js 0.186.0. React Three Fiber не используется.

```sh
npm ci
node scripts/c7-build-local.mjs
node scripts/c7-perf-server.mjs out 3212
```

Открыть http://127.0.0.1:3212/c7/ . Для разработки: `npm run dev`, маршрут `/c7/`. Проект использует static export; `next start` для него не нужен.

## Главные файлы

- `app/c7/` — интерфейс, нативная прокрутка, часы анимации, связь с render Worker.
- `lab/c7-scene/` — авторская непрерывная 3D-сцена, материалы, генерация растительности, подготовленные данные и исходные ресурсы.
- `public/3d/c7/runtime-v646/` — действительно подключённый переносимый runtime, включая одноразовый Worker подготовки травы.
- `public/3d/c7/runtime-v641/` и `runtime-v645/` — неизменяемые контрольные версии для сравнения.
- `content/legal/` — тексты политики, согласий и описание источников.
- [Сводное ТЗ](design/c7-master-tz-2026-10-25.md) и [матрица критериев](design/c7-working-matrix-2026-10-26.csv).
- [Результат v646](design/c7-v646-shading-result-2026-11-08.md) и [план](design/c7-v646-performance-plan-2026-11-08.md) — изменения, измерения, ограничения и оставшиеся работы.

После изменения авторских JS-модулей пересобрать runtime перед Next-сборкой:

```sh
node scripts/c7-package-world.mjs
node scripts/c7-build-local.mjs
```

Packager проверяет происхождение и SHA подготовленных данных; изменение terrain/texture inputs может требовать соответствующего `scripts/c7-bake-*.mjs`. Не обходить эти проверки. Защищённые runtime-v641/v645 не перезаписывать. Исходный HDR для воспроизведения cloud coverage и лицензии ресурсов включены.

## Состояние

v646 исключает заведомо нулевые spot-вклады, кеширует точные солнечные поля крон, параллельно готовит траву на подходящих desktop и освобождает потреблённый пакет. На согласованном Mac-стенде широкий пролёт: v641 33,38 → v645 39,93 → v646 41,40 завершения GPU-команд/с (+24% к641). Это не физически отображаемый FPS; цель +75–100% ещё не выполнена.

На проверенных кадрах изображение сохранено: максимум1/255 относительно641/645. Физические iOS/Android, слабый GPU, настоящий Safari и screen readers не проверены. Мобильная загрузка при4Мбит/с остаётся около5,18с; полное освещение — около6,65с. G04/G07 остаются REWORK; 10/10 не заявлено. Один кейс Extra Meat и подготовка mailto-письма сохранены.

Сборка и функциональные/визуальные проверки выполнены до этого GitHub-снимка. Фразы «без commit/push» в исторических отчётах относятся к предыдущему заданию; последующая отправка на GitHub отдельно разрешена владельцем. Публикация сайта этим push не выполняется.

В Git включены исходники, необходимые runtime/ресурсы, скрипты и текстовые ТЗ/отчёты. Локальные резервные копии, тяжёлые QA-артефакты, старые runtime/стенды и экспериментальные варианты не включены. Исходные локальные файлы не удалены. Часть исторических отчётов ссылается на эти локальные доказательства; они не являются самостоятельными тестами свежего clone. Ключи, .env и настройки хостинга не входят в репозиторий.

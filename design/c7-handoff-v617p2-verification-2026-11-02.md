### Изменённый исходник по отчёту автора: `app/c7/c7.css`

Класс `.c7-about-sheet` — фон секции «О нас».

БЫЛО (4 одинаковых вхождения: базовое + медиа-варианты):
```css
background: linear-gradient(180deg, #eee9de, rgba(238,233,222,.98) calc(100% - 4rem), rgba(238,233,222,0));
```
— непрозрачный «бумажный» лист, 3D за ним не читался.

СТАЛО (все 4 вхождения заменены):
```css
background: linear-gradient(180deg, rgba(238,233,222,.5), rgba(238,233,222,.32) 50%, rgba(238,233,222,.14) 80%, rgba(238,233,222,0) 100%);
```
— верх (под заголовком) 50%, середина 32%, низ полностью прозрачный.

Плюс в базовом правиле добавлена светлая тень текста для читаемости поверх
живой сцены:
```css
text-shadow: 0 .5px 1.5px rgba(238,233,222,.9), 0 1.5px 4px rgba(238,233,222,.7);
```

## Принятые изменения

1. **fused-ground-sky.js / static-shadow-receiver.js / world.js.** Общие texels горизонта и tree visibility для surface/canopy вычисляются в локальной области одного directional loop. Слои сохраняют отдельные веса/visibility, нормали, BRDF и порядок суммирования. Нет нового render pass. Только Chromium/r186/ground receiveShadow=false. Существующий live-deopt при true возвращает прежний shader; WebKit/Firefox сохраняют прежнюю организацию. Compact и full размеры guard-clamp учитываются явно.
2. **lake.js.** Восемь исходных направлений quadrature остаются в том же порядке. Явные постоянные индексы позволяют компилятору сворачивать одинаковые direction/refraction выражения. Только Chromium. Количество выборок, Fresnel, поглощение, волны, отражение и геометрия прежние.
3. **trees.js / c7-leaf-webp.mjs / c7-bake-mobile-profile.mjs / package-world.** PNG авторские источники сохранены. cwebp1.6.0 lossless -exact сохраняет все RGBA, включая RGB прозрачных пикселей. Desktop238115→193806B, mobile300086→232988B. Browser-derived mobile mip tail пересоздан,10 остальных binary derivatives побайтово прежние. Это сокращение передачи, не утверждение о ростеFPS.

Комбинация1+2 отдельно от v642:3 пары AB/BA/AB36.46/36.85/36.88→38.36/38.81/38.75/s, парный выигрыш5.1–5.3%, p50≈28→26мс. Полные версии641/643 затем повторены отдельно. Варианты без полезного эффекта не перенесены из evidence.

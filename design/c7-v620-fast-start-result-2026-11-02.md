## Что изменено

1. Начальное поле берега использует консервативный пространственный поиск ближайшего отрезка вместо проверки всех 256 отрезков в каждой из 204 800 точек. Точные выражения расстояния и пересечения полигона сохранены. Локальный ABBA этого этапа: около 130,5 → 30,9 ms. Все значения совпали в Float64 и Float32, дополнительно проверены 3840 граничных точек.
2. Независимые начальные вычисления четырёх полей склонов идут по столбцам, повторно используя существующий кэш одного X в `ridgeSample`. Итерации последующего сглаживания и формулы не менялись. Полный импорт полей в отдельном Node-тесте: 1022,4 → 760,3 ms. Это ускорение стадии, не обещание такого же процента всему сайту.
3. При отсутствии `scheduler.yield` подготовка уступает очередь через `MessageChannel`, сохраняя периодический таймер для обработки отмены. Порты закрываются в `finally`. В проверенном WebKit native yield отсутствует; Chromium/Firefox сохраняют native путь. [MessageChannel доступен в workers](https://developer.mozilla.org/en-US/docs/Web/API/MessageChannel), [scheduler.yield](https://developer.mozilla.org/en-US/docs/Web/API/Scheduler/yield).

Все десять начальных полей совпали внутри каждого из Chromium/Firefox/WebKit. Существующие бинарные поля повторно подтверждены, а не объявлены заново рассчитанными: происхождение и доказательство эквивалентности записаны в метаданные. Все 16 бинарных ресурсов runtime неизменны по SHA. Графический алгоритм, DPR, геометрическая плотность, материалы, камера, солнечный цикл и отражения сохранены. Фактически используемый runtime — `public/3d/c7/runtime-v620/`.

## Исправление измерителя загрузки

Прежний `visibleMs` некоторых серий, включая v619, записывался после ожидания Playwright. Его внутренний опрос мог добавлять сотни миллисекунд. Такие числа не доказывают точный момент проявления и точный процент ускорения. Отдельные `readyMs` из MutationObserver этой ошибкой не затронуты.

В финальных сериях ниже страница сама записывает timestamp при первом rAF после ready, когда CSS opacity canvas ≥0,98. Проверочный скрипт только считывает сохранённое значение. Это наблюдаемая CSS-видимость, не аппаратное подтверждение презентации кадра. Старые результаты и промежуточная регрессия сохранены с пометками `polling-artifact` / `before-priority-fix`; не используются для финальных процентов.

## Отклонённые варианты и остаток

Кэш коэффициентов посадки травы сохранил атрибуты, но не показал достаточного выигрыша для дополнительной памяти — не включён. Дополнительное ожидание рельефа перед текстурами и полями не помогло ограниченной мобильной сети; `world.js` и `startup-inputs.js` восстановлены по SHA. Проверка истории отсечения, shadow scissor, PMREM, tighter grass bounds и batching не дала новой причины повторять эти GPU-опыты. Частичный scissor под непрозрачным UI не реализован: асинхронная очередь worker может открыть устаревшие неперерисованные пиксели при быстром скролле.

**G07 REWORK:** ×2 FPS и общая загрузка <4 s не достигнуты; 2560 остаётся около 29 FPS. Следующий крупный выигрыш требует компактного набора обязательных первых данных/подготовки по областям и доказанного уменьшения стоимости кадра. Старый S6 и дополнительные проходы без нового доказательства повторять нельзя.

**G04 REWORK:** при просмотре image3 остаются отличия освещённого берега, склонов и крон. В этом проходе художественные параметры не менялись. Физические iOS/Android/слабый GPU, native Safari и VoiceOver/TalkBack — NOT_RUN; USB-проверка не обнаружила телефона, adb отсутствует. **N11/N14 PARTIAL, G08 OPEN.** Гарантия недели хостинга не заявляется, закрепление аккаунта повторно не запрашивается. Extra Meat и отправка через почтовое приложение сохранены. **10/10 не достигнуто.**

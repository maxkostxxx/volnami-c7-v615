# Volnami — актуальные направления c4–c6

Дата: 12 сентября 2026.

## Общий принцип

Три концепта разведены не палитрой, а способом демонстрации работы агентства.
Все используют один точный контент из `content/site.ts` и один обязательный
порядок разделов, но имеют разные hero, навигацию, композицию портфолио,
типографический ритм и поведение интерактивных зон.

Process у всех остаётся горизонтальной полосой со стрелками, а отзывы —
горизонтальной листаемой лентой: это прямые требования исходного DOCX, а не
повторение шаблона.

## c4 — «Портфель в пространстве»

- Характер: точный, предметный, выставочный.
- Шрифты: Playfair Display + Commissioner.
- Основа: холодная светлая экспозиция, глубокий синий кабинет процесса,
  чёрный текст и один оранжевый функциональный сигнал.
- Hero: настоящий Three.js-объект — упаковка «Картофельного Кулька» на основе
  реальной развёртки. Указатель меняет ракурс; до готовности сцены виден
  статический fallback. Reduced motion и Save-Data не запускают WebGL.
- Меню: правый полноэкранный по высоте drawer с modal isolation и собственным
  вертикальным scroll на коротком экране.
- Кейсы: три нерегулярные пространственные экспозиции с реальными работами,
  затем честный текстовый архив кейсов без визуалов.
- Страница кейса: светлая монография с асимметричной историей и галереей.

Силуэт: `текст + физический объект → манифест → тёмная шкала процесса →
редакторские услуги → выставка → бумажная лента отзывов → синий финал`.

## c5 — «Доказательства»

- Характер: документальный, прямой, типографически жёсткий.
- Шрифты: Kreadon + Cannonade.
- Основа: настоящий `#000`, белый рабочий лист и серый служебный слой;
  цвет появляется только внутри реальных проектов.
- Hero: интерактивный редакционный архив. Фокус или клик по названию меняет
  крупный реальный визуал без декоративной фоновой анимации.
- Меню: постоянная левая рейка и чёрный fullscreen takeover; фон изолируется
  через `inert`, фокус удерживается внутри, Escape возвращает его на trigger.
- Кейсы: три разных folio с кликабельными изображениями и заголовками, затем
  строгий directory остальных работ. Помимо Кулька собраны страницы
  «Трансформация реальности» и «Экоранчо».
- Страница кейса: чёрно-белая документальная монография с крупным cover и
  нерегулярной галереей.

Силуэт: `вертикальная рейка + крупное доказательство → широкая строка «О нас»
→ горизонтальная рабочая шкала → табличные услуги → folio/directory → индекс
отзывов → чёрный финал`.

## c6 — «Сцена»

- Характер: театральный, фотографический, режиссёрский.
- Шрифты: Cormorant Garamond + Golos Text.
- Основа: настоящий `#000`, белые титры, холодное серебро и один бледно-розовый
  сценический маркер.
- Hero: реальная фотография проекта. На desktop кадр начинается монохромным,
  а цвет проявляется внутри управляемого указателем spotlight; на touch и при
  reduced motion сразу показывается стабильный полный цвет.
- Меню: непрозрачная нижняя панель примерно 45svh с modal isolation,
  scroll-защитой и безопасной высотой на коротких landscape-экранах.
- Кейсы: горизонтальная сценическая панорама с намеренно разными размерами и
  высотами кадров.
- Страница кейса: тёмная вступительная сцена, белая история и горизонтальная
  галерея на desktop, последовательная галерея на mobile.

Силуэт: `фото-сцена + титр → белый антракт «О нас» → горизонтальная
сценическая шкала → чередующиеся акты услуг → панорама → монологи → чёрный
финал с розовой линией`.

## Squint-test

Даже без цвета направления различаются:

- `c4`: пустая светлая плоскость и один физический объект справа;
- `c5`: плотный газетный лист с постоянной узкой рейкой слева;
- `c6`: широкий тёмный фотокадр и сценический титр справа.

Совпадение секционной последовательности объясняется содержанием ТЗ; формы
секций, интервалы, меню, case-system и интерактивное поведение не совпадают.

## Осознанная редакционная оговорка

В `c6` изображение `tr-11.webp` используется как атмосфера общей сцены, а не
как обложка кейса «Трансформация реальности». Для самого кейса главным остаётся
более сильный проектный визуал.

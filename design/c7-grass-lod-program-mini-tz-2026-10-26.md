# C7 · Q07/G07 · отдельная программа завершённого LOD · v441

Замер v435 показал стоимость vertex-расчётов. Код CPU уже выбирает однотреугольную травинку только когда вся bounding sphere дальше105м: lodMorph=1 для каждого её корня. Но vertex shader продолжает вычислять криволинейный промежуточный стебель/нормали. Новая гипотеза: отдельная программа с константным завершённым morph даст компилятору удалить неиспользуемые расчёты. Плотность/геометрия/ветер/свет/разрешение не меняются. Все общие материальные hooks должны применяться к двум программам, включая occlusion; dispose обеих обязателен.

PASS: парный B/C/C/B пролёт с ощутимым повторяемым выигрышем, совпадение изображения на390/1440/2560 и на границе LOD, отсутствие новой компиляции в пролёте и корректный dispose. До проверки отдельный кандидат, сайт v438. Замеры только после завершения фонового пересчёта полей берега, чтобы не смешивать нагрузку.

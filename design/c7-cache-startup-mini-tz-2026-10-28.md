# C7 — v557: сетевой бюджет кэша геометрии

## Наблюдение

В публичной проверке v555 Firefox и WebKit не достигли ready. Chromium390 прошёл, а1440 попал в fallback: консоль сообщила общий timeout подготовки45секунд; загрузка geometry.bin.gz прервана. Отдельный fetch с этого Mac также получил ConnectTimeout через10секунд, поэтому сетевой сбой нельзя свести только к коду.

В коде найдена самостоятельная проблема: generic loadTerrainGeometry отменяет попытку кэша через1500мс. Файл весит5 443 492байта. После отмены начинается дорогая процедурная генерация; это может съесть оставшийся общий бюджет, хотя сетевой файл ещё мог успешно загрузиться.

## Изменение

Только world.prepareTerrain задаёт timeoutMs8000 для проверенного gzip. Generic loader, проверки SHA, декодер и fallback не меняются. Общий45-секундный лимит и внешняя отмена сохраняются. Искажённый/неверный файл не используется. Изменение не исправляет полный разрыв соединения и не снижает17МБ основных полей ландшафта.

- Прежний1500: fallback на1505мс, один вызов генератора-заглушки.
- Новый8000: loaded на2532мс,830934вершины, проверенные SHA, генератор не вызван.
- HTTP503: fallback за10мс, один вызов.

- Отдельный настоящий createC7Scene с задержанным gzip достиг ready и ground.geometry.userData.terrainCache.mode===loaded. Заглушка используется только в изолированной проверке выбора пути, не в реальном мире.

`backups/c7-v557-pre-cache-budget-2026-10-28/` сохраняет предыдущие исходники.150protectedSHA точны. Native-release меняетworld.js/package.json и сохраняет99файлов проверенного статического экспорта.

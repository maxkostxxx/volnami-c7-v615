# C7 v640 — быстрый отклик, волна движения, работающие отзывы

1. Сохранить v639 и воспроизвести фактический скролл/раскладку отзывов. Изолировать стоимость большой маски от 3D. Существующую работу и runtime не упрощать.
2. Заменить SVG-маску на короткий каскад движения самого содержимого: каждый видимый текст/карточка поднимается по плавной дуге, без скрытия целой секции и ожидания чанка. Запуск у края экрана; повтор вниз/вверх. Ввод/фокус/пауза/ссылки не должны вызывать скачки.
3. Вернуть центрированную карусель отзывов с одинаковым шагом, циклическими стрелками, свайпом и клавиатурой. Автосмена только в видимой вкладке и видимой карусели; явная пауза, остановка при чтении/взаимодействии/reduced motion.
4. Убрать подтверждённую лишнюю работу при скролле. Сравнить v639/v640 на одинаковых завершениях GPU и на ритме DOM-анимации; не выдавать rAF за FPS. Сохранить непрерывную 3D-сцену и детализацию.
5. Два визуальных прохода на desktop/mobile, 390/1440/2560, быстрый/обратный scroll, carousel и form, итоговая сборка/пакет/публикация/публичная проверка. Обновить документы с реальными ограничениями.

Дизайн: рассматривались «движущаяся волновая завеса», «rolling lift», «статические линии и fade». Выбран rolling lift: непосредственно содержимое поднимается и мягко оседает, последовательность идёт слева направо; никаких дополнительных рисованных лент. Сохраняются брендовые Kreadon/Cannonade, лесные/кремовые/розовые токены и существующий макет. Длительность, подъём и короткий шаг вынесены в tokens.css. Навыки: jp-frontend-design, frontend-design, gsap-performance/react. Для compositor-анимаций используется native Web Animations API без ожидания загрузки движка.

Пункты1–5 выполнены;8812d00 опубликован до следующего поручения. Public UI3ширины и smoke2ширины PASS. Общая GPU-производительность остаётся открытой: blank30Hz ограничивает текущий тест. См. результат.
